# Changelog

PhotoFolio 主题的版本更新记录。格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)。

## [0.5.12] — 2026-09-14

### Added
- **首页轮播图数量可配置**：`hugo.toml` 新增 `carouselCount` 参数控制首页轮播展示的精选图数量，取值自动钳制在 1–12 张（默认 12 张，超界按边界值处理）

### Changed
- **瀑布流跨档位 FLIP 动画**：窗口跨行数档位断点（500/768/1000，带滞回）重新分行时，照片以 FLIP 动画平滑移动到新位置（0.35s，缓动与足迹时间线列数切换一致），拖拽跨档不再瞬间跳变；档位内冻结行成员的比例缩放仍实时无动画；动画前清除上一轮残留 transform 保证 First 测量干净，`prefers-reduced-motion` 时跳过
- **筛选栏标签样式**：全部作品页筛选栏的维度标签（拍攝年份等）字号 0.65em → 1em，去除 0.25em 字间距
- **足迹地图标题精简**：移除中文标题「拍攝足跡 · 世界地圖」，英文眉题 FOOTPRINT MAP 字号加大（`--size-small` → `--size-h3`）作为区块主标题，`aria-labelledby` 改指向眉题，删除不再使用的 `footprint_map_title` i18n 键
- **足迹地图圆角统一**：地图框 `.footprint-map` 圆角 0.25em → 0.75em，与时间线内容卡片圆角一致
- **窄屏轮播指示器改为小圆点**：窄屏（<768px）不再隐藏指示器——横条进度条改为小号圆点竖排（正在播放的圆点变为绿色并以弹簧曲线弹入放大，其余为半透明白色圆点），当前图片标题仍显示（标题宽度上限收窄适配小屏），切换时标题以 0.6s 渐变缓慢展开/收起；指示器底部高度宽窄屏统一固定为 5rem；跨断点（768px）切换时圆点与横条以 0.35s 平滑变形互转（宽/高/圆角/行距/位置/内边距同步过渡）；窄屏指示器字号缩小、行间距收紧，圆点加横向内边距扩大点按区域、文字与圆点间距加大；窄屏无 hover 交互，未播放项悬停显示标题与进度填充动画仍仅桌面端生效，窄屏自动播放照常由 JS 定时器驱动
- **首页轮播标题窄屏缩小**：hero 标题与副标题窄屏（<768px）字号稍小（标题 3.2em→2.6em，副标题 1.35em→1.1em），跨断点切换时字号以 0.35s 平滑过渡
- **导航跨断点切换动画**：宽窄屏跨过 768px 断点时水平滑动切换——进入窄屏：菜单文字临时回到导航栏内向右滑出淡出「转换」为汉堡按钮（从右侧滑入淡入）；进入宽屏：汉堡消失、菜单文字从右侧向左滑回原位；三段动画时长统一 0.6s，与首页进度条标题切换速度一致；滑出期间导航以绝对定位脱离文档流（锚定 `.header-actions`、贴汉堡左侧）并强制单行，不挤压站名、不换行；由 JS 监听媒体查询变化在断点跨越瞬间驱动（页面加载不触发），`prefers-reduced-motion` 时跳过动画

### Fixed
- **足迹地图标题宽窄屏字号不一致**：`.footprint-map-title` 引用了去冗余清理中已删除的 `--size-h2` 变量，宽屏下声明失效、字号回退为继承的正文 16px，而窄屏另有 1.5em 硬编码覆盖，导致两侧字号差异——改为统一使用 `var(--size-h3)`（1.5em）并移除窄屏覆盖，宽窄屏字号一致
- **窄屏菜单开合背景颜色堆叠**：顶部透明时打开汉堡菜单，导航栏主体与下拉面板各自渐变背景，面板上滑过程中顶部压在导航栏下方，交界处两片半透明背景叠加产生更深色带、填充过程断裂——改为面板从视口顶部（`top: 0`）开始，背景延伸覆盖整条导航栏并以负 `z-index` 垫在站名等导航栏内容之下（内容下移避开，`padding-top` 6.5em），`menu-open` 不再渐变导航栏背景、隐藏底边线（含滚动态），开合时整块背景由面板单一元素统一渐变，站名不被遮挡、交界处无缝无堆叠
- **窄屏 SPA 返回首页后导航栏不透明**：移动端打开汉堡菜单后点击首页链接，SPA 切换页面时只移除了菜单面板的 `active` 状态，未清理 `.site-header` 上的 `menu-open` 类，导致返回首页后导航栏保持不透明背景；现在切换页面时同步移除 `menu-open`

## [0.5.11] — 2026-09-13

### Added
- **图片 OSS 多尺寸 + WebP 优化**：扩展 `img-url.html` 支持阿里云 OSS 图片处理参数，按场景输出不同尺寸与格式的图片
  - 瀑布流照片卡片：输出 `w_800` 缩略图与 `w_1920` 灯箱大图，分别通过 `data-src` 与 `data-full-src` 加载
  - 首页轮播图：`w_1920` WebP 占满视口
  - 首页分类卡片封面：`w_1000` WebP
  - 足迹时间线缩略图：`500×500` 居中裁剪 WebP
  - OG / Twitter Card：`1200×630` 居中裁剪 WebP
  - 灯箱读取 `data-full-src` 展示大图，并在打开时预加载相邻两张大图
  - 所有尺寸与质量均可在 `hugo.toml` 的 `[params.imageSizes]` 中配置
- **首页轮播指示器改为右下角进度条**：轮播图右下角垂直排列；每个指示项由图片标题 + 水平进度条组成，非当前项只显示短灰色条，当前项显示标题并播放绿色进度填充；进度条动画仅作为视觉反馈，自动播放改由 JS `setInterval` 驱动，因此进度条在窄屏隐藏后轮播仍能正常自动切换；点击非当前进度条跳转对应图片并继续轮播，点击当前进度条不重置、不暂停；鼠标事件均不暂停轮播；悬停非当前项时显示该照片标题（透明度更低、颜色更暗，与当前播放项区分），当前项 hover 保持原样式不变；轮播图图片改为 `loading="eager"`，首屏第一张幻灯片在 HTML 中默认带 `active` 类，JS 初始化延迟一帧强制启动动画，修复首屏第一张图黑屏/无法自启动的问题；移除点击轮播图跳转到 `/featured/` 的链接；轮播图底部新增向下滚动箭头（SVG 存于 `data/svg.toml`），点击使用自定义 ease-out 曲线平滑滚动到轮播图底部刚好被导航栏遮挡的位置（起始较快、接近目标时减速），箭头无背景、带抛物线式上下微动动画（下落整体加速，但触底前轻微减速；75% 时间下落 0.5em，底部瞬间反弹后快速回升，到顶部前轻微加速），所有屏幕尺寸可见；进度条指示器仅在桌面端（≥768px）显示；轮播图幻灯片切换过渡从 0.8s 延长至 1.2s，进度条走满时间从 4s 延长至 5s

### Fixed
- **超窄屏（≤500px）行布局失效**：去冗余重构时 `getTargetRowHeight` 丢失档位 0 特例（基准张数 N 应映射为 1），档位 0 被按每行 2 张排布、末行照片高度被压至正常的一半——恢复「档位 0 = 单张 3:2 占满整行」后，横构图独占一行、竖构图与相邻横构图同行、末行高度正常

## [0.5.10] — 2026-09-13

### Added
- **足跡世界地圖**：`/footprint/` 时间线顶部新增 SVG 世界地图（自绘等距圆柱投影，零外部库/瓦片；世界陆地几何为一次性生成的简化静态 JSON，同源 fetch 并记忆化已解析数据——SPA 返回重进本页照常渲染，失败降级为网格+光点且下次重试）——按省份/国家聚合金色光点（大小随照片数），悬停/键盘聚焦弹层显示地名、照片数与年份跨度，点击光点跳转对应足跡详情页（SPA 无缝切换）；视图自动适配到全部拍摄地点（fit-to-bounds + 纵横比锁定）；带边框圆角的长方形地图框架（内容裁剪到视图内不外溢），区块宽度与导航栏一致；IntersectionObserver 懒加载（rootMargin 600px）；交错弹入动画与多照片首点呼吸脉冲环；`prefers-reduced-motion` 完整降级；明暗主题全变量适配；坐标数据新增 `data/locations.toml`（无坐标地点自动跳过）
- **全部作品筛选**：`/gallery/` 全部作品页新增筛选栏——拍攝年份 / 拍攝地點 / 作品類型三组胶囊按钮（参考 chuweimin 同款：行首文字标签 + 全部按钮 + 横向滚动胶囊、右侧渐隐遮罩、选中高亮，可组合，默认全部），选项从当前页照片推导（年份降序、地点/类别按照片数降序），切换后选中项自动滚入可视区；**筛选维度由 `hugo.toml` 的 `[params.galleryFilters]` 控制开关**（year/location/category，缺省仅开启年份）；筛选切换以「下拉加载更多」分页模式重启网格——集合外隐藏、集合内重新分页（首批 12 张、滚动加载后续批次，任何筛选状态都保持下拉加载更多）；筛选状态同步到 URL（`?y=` 年份、`?l=` 地点英文 slug（对应足迹页文件名，如 guangdong/japan）、`?c=` 类型，`history.replaceState` 不产生历史记录，默认值不写入），直接打开带参数链接或浏览器后退自动恢复筛选；无匹配显示空状态文案并隐藏触发器；照片卡片补 `data-year/location/category` 属性驱动匹配

### Fixed
- **批次尾行合并不生效（行末空白、照片被挤到下一行）**：`_incompleteStart` 去状态化时用「当前待加载队列非空」推导尾行，但尾批到达时队列已被消费，导致上一批未完成尾行不再与下一批合并——卢村秋景右侧留白、黛瓦灯影另起一行即此症状；改为按「上一批最后一行是 ragged（左对齐尾行）」推导（有新批次到达时 ragged 尾行必为待补齐尾行），恢复尾行合并
- **筛选切换后照片乱序**：行容器拍平（flattenRows）时照片被追加到网格末尾，多次切换筛选后游离照片与行内照片的相对顺序反转、不再按时间排序——改为插回第一个游离照片之前，保持文档序=时间序
- **首屏行宽偏差隐患**：行容器出现前 getRowGap 回退硬编码 4px（间距已改为 0.5em/8px），导致首批行宽计算偏差——改为读网格自身 rowGap 并缓存
- **SPA 换页监听器泄漏**：masonry 的 ResizeObserver 与无限滚动的 scroll 监听在换页后仍持有已脱离文档的网格子树——初始化时断开旧观察/旧监听（无限滚动清理提前到早退之前）；gallery-filter 的窗口 resize 监听改为模块级单例

### Changed
- **代码去冗余**：档位判定改为阈值数组驱动（原 4 段嵌套三元）、行高公式收敛为唯一 rowHeight 助手（原 3 处实现）、删除可推导的 _incompleteStart 状态与 partitionRows 无用参数；弹层数据改存光点 dataset（去掉点数组回查与投影坐标回写）；时间线圆点 SCSS 去重；全站照片时间排序管线提取为 `partials/photo-sorted.html`、足迹地点注册表提取为 `partials/location-registry.html`（slug/URL/坐标一次构建，6 个模板共用）；足迹聚合改单趟累积（原嵌套 where/in）；筛选开关解析一次成 dict
- 轮播图：鼠标悬停不再暂停自动播放（仅键盘聚焦圆点时暂停）
- 瀑布流照片间距增大：0.25em → 0.5em（行宽/行高计算自动读取真实间距，无需改动引擎）
- **移除全站面包屑**：分类/足迹/组照等所有页面去掉 breadcrumb 导航（多余元素），清理对应 CSS 与 i18n 键
- **照片卡片悬浮上移**：瀑布流悬停效果由「图片放大 scale(1.03)」改为「整卡轻微上移 translateY(-0.15em)」（弹簧曲线），与首页分类卡片一致但幅度更小（分类卡片为 -0.35em）
- **超窄屏照片行布局**：宽度 ≤500px 时照片网格每行 1–2 张——3:2 横构图独占一行（占满整行），竖构图绝不落单（与相邻横构图并排一行，尾行竖构图并入前一张横构图）；行基准档位新增超窄屏档（滞回回升 520px），与既有 768/1000 断点档位一致

## [0.5.9] — 2026-07-01

### Added
- **精選分類**：新增 `/featured/` 页面，自动收集所有标记 `featured = true` 的照片（跨分类、按时间排序）；首页分类卡片自动统计精选数量并以最新精选照片为封面，精選卡片置於首位（其余分类权重依次后移）
- **精選单张展示**：組照照片標記精選時僅展示該單張（不帶組照鏈接與徽章，標題為照片自身 alt），組照內頁標記精選也照常顯示；`photo-card` 参数 `isInSeriesPage` 重命名为 `asIndividual`

### Changed
- **分类重组**：城市、乡村、山河合并为「風光」（`scenery`，43 张）；人文、花木、動物保持不变；首页分类卡片顺序：風光、人文、花木、動物
- **首页改版为全屏轮播**：轮播展示按时间降序最新的 12 张精选图（`featured=true`），充满整个页面（`object-fit: cover` 居中适当裁剪、无白边）；标题与副标题悬浮在轮播图左下角（底部渐变压暗保证可读）；自动播放 4s/张 + 左右箭头 + 圆点，悬停/聚焦暂停；点击照片可打开灯箱；分类入口移到轮播图下方，下拉滚动后可见（滚动进入视口时交错渐入）
- **顶部导航栏透明**：页面顶部时 header 背景完全透明（无背景/边框/模糊），下拉滚动（>10px）后显示背景色与毛玻璃
- **照片网格改为两端对齐行布局（自然行高，零裁切）**：行高 = (行宽 − 间距 − 边框) / 宽高比之和，由本行照片内容自然决定、恰好铺满容器；贪心分行以「每行 N 张 3:2 宽幅照片」为参考值，边界处比较「停在此处 / 纳入下一张」取行高最接近参考值的方案——行高天然落在参考值 ±10% 内（肉眼看基本一致）；**行基准档位与屏幕宽度对应（断点与汉堡图标一致）**：≤768px 每行 2 张基准、769–1000px 每行 3 张基准、>1000px 每行 4 张基准（滞回 788/1020）；照片严格保持自身长宽比（`object-fit: cover` 仅兜底取整误差），绝不拉伸、绝不粗暴裁切、行末不留空白；**最后一行（照片耗尽、只剩一两张时）不强行对齐：行高封顶参考值、右侧留白，照片高度与其他行一致**；宽屏每行至少 2 张，独占一行的照片按自然比例显示；按时间顺序横向逐行加载（60ms/张），resize 由 JS 重排（不改变照片顺序）；间距 0.25em；灯箱放大仍为原图比例
- **照片卡片悬浮效果**：悬停时卡片不再上移，改为照片本身轻微放大（`scale(1.03)`，带回弹的弹簧曲线），位置固定；**卡片不显示任何元信息**（悬停无标题），标题与完整元信息仅在灯箱放大后显示——通过 `data-title` 等属性传入灯箱，放大图底部显示：第一行标题，第二行地点/日期/拍摄参数（各带 SVG 图标，组间空格分隔，分类标签不显示）

### Fixed
- **行末照片换行错位**：容器宽度向下取整并留 2px 安全余量、图片宽度只舍不入，杜绝四舍五入误差与滚动条出现/消失导致的整行超宽换行（行末留白、行内“高度不一致”均由此引起）；网格挂 `ResizeObserver`，尺寸变化自动重排行布局
- **「已加载全部照片」文案保留**：加载完成后不再 2 秒后移除；全部照片不足一页时也直接显示完成文案
- **下拉加载卡在「载入中」**：每批加载完成后检查触发器是否仍在视口内——在视口内则直接继续加载下一批，不再依赖「离开→进入」的滚动转变（此前照片未把触发器推出屏幕时观察器不会再次触发，需上下滚动才能继续）
- **无限滚动不再提前触发**：观察器底部负边距 120px，触发器进入视口 120px 后才加载，避免还没滚到最下方就提前加载
- **灯箱毛玻璃背景**：放大照片时背景改为当前照片铺满屏幕（`object-fit: cover`）+ 模糊（24px）+ 压暗层的毛玻璃效果，切换照片时背景跟随主图
- **拖拽变宽/变窄时布局来回跳跃、行末错位**：resize 改为「先按比例缩放照片（行成员冻结不动）、仅跨窄屏断点才重新分行」；窄屏断点（700px）加滞回（≤660 进窄屏、≥740 回宽屏）；行划分在揭示新批次后以全部照片为坐标系保存复用；**重排改为 rAF 逐帧执行（去掉 100ms debounce）**——此前 debounce 滞后使布局宽度停留在旧值、行宽超过已变窄的容器导致每行末张换行错位；同时清除残留 inline margin

- **行末错位（引擎行与视觉行不一致）**：每个引擎行改为显式 `.masonry-row` 行容器，引擎行 = 视觉行，杜绝 flex 自动换行把相邻行合并导致的错位
- **批次末尾行等待补齐**：每批末尾行按统一行高左对齐等待，下一批到达时合并重新组成完整行（尾行照片的最终大小由补齐后的行内容决定，不做单独裁满整行的处理）；全部照片加载完后真正的最后一行保持左对齐留白
- **SPA 首跳瀑布流空白**：未揭示照片的 `is-hidden` 改为由 `initMasonry` 统一添加（baseof 内联脚本在 SPA 注入时不执行，此前未隐藏的照片以原始尺寸占据版面、把已排好的行顶到页面底部）；图片改为 `data-src` 按批显式加载（不依赖浏览器原生懒加载）；揭示等待测量最多 800ms——快速路径直接用真实比例（动画连贯），慢速路径先按兜底比例揭示、测量完成后等动画结束再校正（不打断动画）

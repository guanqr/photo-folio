## [0.19.0] — 2026-10-18

### Added
- **灯箱图像分析加载失败提示**：探测图加载失败（网络/未开 CORS）或采样渲染异常时原为静默隐藏全部图表区、无任何反馈——改为与筛选空状态同款的提示卡片（虚线框 + 新增 alert 警告图标 + 文案「無法載入分析結果，請檢查網絡連線」），构建期预渲染于图表容器末尾、JS 按探测结果切换 hidden（失败显示、成功/缓存命中隐藏，收起再展开自动重试；切图时 analyze 入口先收起上次提示、成功/失败路径各再置位）；灯箱内无底色、图标与文字上下居中排布（图标 3.2em + 小号文字 0.8em、面板内收紧，display 限定 :not([hidden]) 防压过 UA 的 hidden 规则；虚线框取亮色 `--color-text-muted`——灯箱内 `--color-border` 固定为暗色不可见；上下边距与正常图表区块同构——上 1.1em 与 EXIF 同距、下 0 由收起按钮自带 1.1em）；中屏双列网格占满整行并自分隔线规则排除（图表开关配置变化会改变其 DOM 序号、偶序时被误当第二列项）；随图片切换与面板同步淡入

### Fixed
- **明暗主题切换文字/标题滞后（不同步）**：H2 标题（%section-heading）/导航文字（.site-nav a/.nav-parent、.logo-text）与 body 自 0.17.0 起带 0.3s 元素级颜色过渡，0.18.0 又叠上 View Transitions 整页快照交叉淡化——切换时这些元素在交叉淡化下仍跑自身渐变、有效进度约为两者乘积，明显滞后于卡片等瞬时换色元素——主题切换窗口（html.theme-switching，既有挂类机制）内全站过渡统一压制，切换动作瞬时完成、动画由 VT 交叉淡化唯一提供（无 VT 浏览器退回瞬时切换，全站同刻换色）；header 既有的 theme-switching 临时过渡规则随压制成为死规则、一并删除
- **亮色主题首页导航下拉菜单文字不可见（自定义属性自引用循环）**：HSL 迁移把 .nav-dropdown 的「还原主题色」写成 `--color-text: var(--color-text)` 自引用——自定义属性引用自身构成循环、判定 guaranteed-invalid，面板内文字色回退继承 header 强制的白字、白字压浅白面板不可见——改按主题分量重建（`hsl(var(--color-text-h), …)`）：header 强制规则只覆盖主值、分量仍指向亮色主题值
- **无限滚动跨页摘监听**：SPA 跳转时旧页末批加载的异步收尾经模块级槽位摘除新页面的滚动监听、致新页剩余作品加载不出——收尾加页面归属守卫、拆线仅作用本实例
- **主题切换窗口内打开灯箱面板不可见**：主题切换窗口的全站过渡压制（`!important`）压过缩放浮现的普通内联过渡、transitionend 不触发致面板卡在隐藏态——缩放/收起的内联过渡以 important 同级写入（内联重要声明压过样式表重要声明），清理改 removeProperty（普通赋值清不掉 important 声明）
- **主题切换窗口内移动菜单开合残留陈旧收尾**：过渡被压制时 transitionend 不触发、上次开合的收尾监听残留，下次开合的首个 transitionend 会拦腰清掉在途过渡——收尾监听入槽位、每次开合前先作废旧监听与残留内联过渡
- **滑动接管作废在途滑出/滑入收尾**：触屏横向接管把主图过渡置 none、在途滑出/滑入的 transitionend 永不触发，残留收尾监听会在回弹/下一次切图的 transitionend 上重放（未达阈值的回弹仍把照片换掉/提前恢复裁剪）——接管时经钩子摘除在途滑出与滑入两个收尾监听
- **水平接管残留拖拽禁选中**：横向接管结束拖拽时不摘 is-dragging 类（收尾路径因状态已复位早退），面板文字整场无法长按选择——接管分支与状态成对摘除
- **灯箱背景 AVIF 重试再失败无恢复**：AVIF 失败转 webp 重试时 error 监听被消费，webp 再失败死层永驻、背景纯黑直到下次切图——重试在途不删层、重挂监听等待重试结果（成功走淡入、失败走删层与上一层淡回）
- **关闭缩小动画尾部被切断**：关闭容器的 0.35s 内联过渡与缩小动画同时长，却同任务被无条件清空（从未生效）、容器退回样式表 0.3s、缩小尾部 0.05s 被 visibility 提前翻转切断——清除移入缩小收尾、覆盖全程生效
- **分析区收起回滚动画不被再展开取消**：收起启动的内容回滚在快速重新展开后仍逐帧强制 scrollTop 归零、覆盖用户滚动输入——抽屉导出回滚取消、展开分支调用
- **明度曲线金色收编 CSS 变量**：直方图明度曲线与图例圆点的金色原为 JS 字面量 rgb 值（颜色体系唯一 JS 例外）——收编为 --dark-lum-curve 四元组（样式表设定 stroke 与圆点背景），JS 不再持有颜色字面量
- **测量失败比例污染网格缓存**：无宽高属性照片的 error 路径把兜底比例（1.5）经 settle 永久写入比例缓存、阻断后续真实比例（AVIF 转 webp 重试成功后 load 写不进）——error 不写缓存也不结束测量，失败由超时兜底结束（与超时同款只影响本次排布）
- **无网格页跳转残留旧网格观察器**：ResizeObserver 断开仅在存在网格的新页执行，跳转无网格页（关于/足迹列表/首页/404）时旧观察器持续持有已脱离文档的整棵作品子树——断开移到早退之前（与懒加载同款清理先于早退）
- **分类卡观察器早退在断开之前**：换页后无未揭示卡片的页面直接早退、旧 IntersectionObserver 持续持有首页卡片子树——断开移到早退之前
- **网格间距兜底硬编码**：行间距读取失败时以 8px 臆造值参与行宽计算（与 CSS 声明脱钩、根字号/间距改动后行宽错档）——只缓存真实读取值，读取失败按 0 参与本次排布且不缓存
- **瀑布流揭示两段式**：.masonry-item 的 transform 过渡写成「0.4s + 弹簧变量」，变量自带时长使展开后成双时间值、第二个按规范解析为 delay——每张照片先淡入、停顿后突然上滑——时长由变量自带、删除前缀
- **FLIP 收尾定时器残留**：分类卡与关于页统计卡的 400ms 收尾定时器无槽位，快速二次断点翻转时旧定时器清掉第二次动画在途的内联样式（卡片中途急停）——定时器入各网格槽位、新翻转前先作废旧收尾（关于页头部翻转同修）
- **轮播断点差 1px**：轮播 6 处桌面断点 min-width:768px 与全站 769 分界不一致，768px 视口同时命中两套体系——统一改 769（导航滑入动画断点同修）

### Fixed
- **「宽窄切换后页面放大」根因定位与修复**：宽窄切换/快速来回切换时，分类网格列数切换的 FLIP 动画（cards-flip 的 Invert 阶段 translate/scale 把卡片摆回旧列位置）产生 **transform 视觉溢出**——旧列位置超出新视口宽度，transform 溢出进入 body 的 scrollable overflow（scrollWidth > clientWidth），浏览器（Chrome 模拟器与真机同款行为）据此启用适配缩放且**不回退**，页面「放大」直到人工缩小——`.grid` 容器加 `overflow-x: clip` 裁剪 FLIP 瞬态溢出（不创建滚动容器、不参与视口传播规则）；`html`/`body` 另加根级 `overflow-x: clip` 兜底（hidden 参与视口传播规则、body 的 used 值会被置回 visible 而不裁剪）；无头高压验证（5 轮连续收窄 240-900px + 20 轮快速来回切换密集采样）全程无溢出无缩放偏移

### Changed
- **首页改版为全屏轮播**：轮播展示按时间降序最新的 12 张精选图（`featured=true`），充满整个页面（`object-fit: cover` 居中适当裁剪、无白边）；标题与副标题悬浮在轮播图左下角（底部渐变压暗保证可读）；自动播放 4s/张 + 左右箭头 + 圆点，悬停/聚焦暂停；点击照片可打开灯箱；分类入口移到轮播图下方，下拉滚动后可见（滚动进入视口时交错渐入）
- **顶部导航栏透明**：页面顶部时 header 背景完全透明（无背景/边框/模糊），下拉滚动（>10px）后显示背景色与毛玻璃
- **照片网格改为两端对齐行布局（自然行高，零裁切）**：行高 = (行宽 − 间距 − 边框) / 宽高比之和，由本行照片内容自然决定、恰好铺满容器；贪心分行以「每行 N 张 3:2 宽幅照片」为参考值，边界处比较「停在此处 / 纳入下一张」取行高最接近参考值的方案——行高天然落在参考值 ±10% 内（肉眼看基本一致）；**行基准档位与屏幕宽度对应（断点与汉堡图标一致）**：≤768px 每行 2 张基准、769–1000px 每行 3 张基准、>1000px 每行 4 张基准（滞回 788/1020）；照片严格保持自身长宽比（`object-fit: cover` 仅兜底取整误差），绝不拉伸、绝不粗暴裁切、行末不留空白；**最后一行（照片耗尽、只剩一两张时）不强行对齐：行高封顶参考值、右侧留白，照片高度与其他行一致**；宽屏每行至少 2 张，独占一行的照片按自然比例显示；按时间顺序横向逐行加载（60ms/张），resize 由 JS 重排（不改变照片顺序）；间距 0.25em；灯箱放大仍为原图比例
- **照片卡片悬浮效果**：悬停时卡片不再上移，改为照片本身轻微放大（`scale(1.03)`，带回弹的弹簧曲线），位置固定；**卡片不显示任何元信息**（悬停无标题），标题与完整元信息仅在灯箱放大后显示——通过 `data-title` 等属性传入灯箱，放大图底部显示：第一行标题，第二行地点/日期/拍摄参数（各带 SVG 图标，组间空格分隔，分类标签不显示）

### Fixed
- **行末照片换行错位**：容器宽度向下取整并留 2px 安全余量、图片宽度只舍不入，杜绝四舍五入误差与滚动条出现/消失导致的整行超宽换行（行末留白、行内“高度不一致”均由此引起）；网格挂 `ResizeObserver`，尺寸变化自动重排行布局
- **「已加载全部照片」文案保留**：加载完成后不再 2 秒后移除；全部照片不足一页时也直接显示完成文案
- **下拉加载卡在「载入中」**：每批加载完成后检查触发器是否仍在视口内——在视口内则直接继续加载下一批，不再依赖「离开→进入」的滚动转变（此前照片未把触发器推出屏幕时观察器不会再次触发，需上下滚动才能继续）
- **无限滚动不再提前触发**：观察器底部负边距 120px，触发器进入视口 120px 后才加载，避免还没滚到最下方就提前加载
- **灯箱毛玻璃背景**：放大照片时背景改为当前照片铺满屏幕（`object-fit: cover`）+ 模糊（24px）+ 压暗层的毛玻璃效果，切换照片时背景跟随主图
- **拖拽变宽/变窄时布局来回跳跃、行末错位**：resize 改为「先按比例缩放照片（行成员冻结不动）、仅跨窄屏断点才重新分行」；窄屏断点（700px）加滞回（≤660 进窄屏、≥740 回宽屏）；行划分在揭示新批次后以全部照片为坐标系保存复用；**重排改为 rAF 逐帧执行（去掉 100ms debounce）**——此前 debounce 滞后使布局宽度停留在旧值、行宽超过已变窄的容器导致每行末张换行错位；同时清除残留 inline margin
- **无限滚动时旧照片位置变化**：揭示新批次改为只对新批次分行（已显示照片的行划分与位置永久不变，原独占一行的照片保持独占）；跨断点重分行与揭示使用同一规则（含边界微调），窄屏→宽屏切换后的布局与初次宽屏一致
- **行末错位（引擎行与视觉行不一致）**：每个引擎行改为显式 `.masonry-row` 行容器，引擎行 = 视觉行，杜绝 flex 自动换行把相邻行合并导致的错位
- **批次末尾行等待补齐**：每批末尾行按统一行高左对齐等待，下一批到达时合并重新组成完整行（尾行照片的最终大小由补齐后的行内容决定，不做单独裁满整行的处理）；全部照片加载完后真正的最后一行保持左对齐留白
- **SPA 首跳瀑布流空白**：未揭示照片的 `is-hidden` 改为由 `initMasonry` 统一添加（baseof 内联脚本在 SPA 注入时不执行，此前未隐藏的照片以原始尺寸占据版面、把已排好的行顶到页面底部）；图片改为 `data-src` 按批显式加载（不依赖浏览器原生懒加载）；揭示等待测量最多 800ms——快速路径直接用真实比例（动画连贯），慢速路径先按兜底比例揭示、测量完成后等动画结束再校正（不打断动画）
- 照片卡片圆角减小：0.5em → 0.25em；组照徽章整体缩小（高度 2em → 1.5em，图标与数字同步缩小）
- **照片元信息悬浮显示**：瀑布流不再在照片下方单独展示元信息，改为透明渐变底悬浮覆盖在图片底部（仅标题，字号 1em→0.9em、字重 600→400），鼠标悬停/键盘聚焦时**纯淡入浮现（无上移动画）**；渐变阴影减弱（黑 0.8→0.6）；触屏设备（无悬停）元信息常显
- `photo-wrapper` 统一改为 div 容器，组照封面链接缩为内层 `a.series-link`（避免 a 嵌套 a）；灯箱点击委托增加链接守卫；分类标签链接移除，清理相关 CSS/i18n 冗余条目

### Fixed

- 宽屏/窄屏切换时首页标题间距突变：删除移动端 `padding: 2em` 覆盖

## [0.5.0] — 2026-06-27

### Added
- **瀑布流 JS 引擎**（`masonry.js`）：显式列容器 + round-robin 初始分配，替代 CSS `column-count`
- **resize FLIP 动画**：列数互切时位移+缩放平滑过渡（0.35s），自动保持滚动位置
- **足迹时间线 FLIP 动画**（`timeline-anim.js`）：JS 接管整卡 flex 布局、缩略图网格列数、竖线/圆点位置，跨越 768px 断点时统一 FLIP
- **inline 隐藏脚本**（`baseof.html`）：同步执行，在浏览器触发 lazy loading 前标记首批之外的 `.is-hidden`

### Changed
- **首屏加载策略**：inline script → masonry 初始化 → infinite-scroll 分发的三阶段管线
- `infinite-scroll.js` 基于 `grid._allItems` 原始时间序索引，不依赖 DOM 顺序；加载延迟 300ms → 800ms
- **移动端导航**：汉堡按钮 `display:none` → `visibility+opacity` 淡入淡出；菜单动画由 JS 动态注入 transition（`transitionend` 后清除）
- **CSS 架构**：移除 `_responsive.scss` 中由 JS 接管的规则（`.masonry-grid` flex-direction、`.timeline-gallery` 列数、`.timeline-node` / `.timeline-date` 移动端布局）。竖线/圆点改用 CSS 自定义属性（`--tl-line-left` 等）
- **全站内部链接**：`Permalink` → `RelPermalink`，`BaseURL` → `/`
- `.masonry-item`、`.timeline-thumb`、`.series-badge`、`.timeline-content` 统一 `transition: transform 0.35s`

### Fixed
- CSS columns 加载更多时已有照片位置跳变
- resize 后 loadMore 隐藏项全部挤入同一列：`rebuildAndDistribute` 脱离 DOM 后测高为 0 → 引入虚拟 `colHeights[]` 跟踪 + 入参 `firstMap` 预测量高度
- FLIP 元素索引错配：`allRendered.sort()` 原地排序导致 `firstRects[i]` / `lastRects[i]` 非同一元素 → `Map<Element, Rect>` 按元素查找
- FLIP Play 阶段清除 `transformOrigin` 导致缩放原点从 `top left` 跳回 `center` → 保留不清除
- `visibility:hidden` 阻止浏览器原生 lazy loading → 移除，用同步 inline script + round-robin 替代
- `getBoundingClientRect()` 在初始分配时每轮强制同步 layout → round-robin 替代最短列
- 足迹页面 `+N` 未计入组照内页数量
- `.series-badge` FLIP 动画时长与卡片不一致（0.3s vs 0.35s）
- mobile nav 跨越 768px 断点时从桌面可见态过渡造成闪烁
